# Changelog — Alter

## 0.1.0

- **Claude Code backend** — use your local `claude` subscription (agentic, Opus/Sonnet/Haiku), alongside any OpenAI-compatible endpoint.
- **Per-chat model** — each conversation keeps its own connection, model, and effort.
- **Projects** — group chats under a project with its own folder and instructions.
- **Command palette** (⌘K), **global hotkey** (⌘⇧Space), and **branch a chat**.
- **Token & cost meter**; `/usage` and `/compact` (token-free).
- **Open in Alter** — the companion extension opens a seeded chat here.
- **Browser bridge + extension** — token-gated local bridge so the extension reuses your connections with no keys in the browser.
- Memory, file tools, attachments, streaming chat, routines, tray + launch-at-login.
